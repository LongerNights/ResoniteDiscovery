## Confirmed from batch 1 (no action needed)

- `SearchSortParameter` = CreationDate, LastUpdateDate, FirstPublishTime, TotalVisits, Name, Random.
- `SearchSortDirection` = Ascending, Descending.

  reflection on a `SyncType`. Not usable for us without a registered data-model type (rule 6).

## UIBuilder facts learned from the first in-game run (2026-11-02, ilspy `FrooxEngine.UIX.UIBuilder`)

- `Panel(tint)`, `Panel()`, `VerticalLayout`, `HorizontalLayout`, `GridLayout`, `OverlappingLayout`, `Slider` and `Button` all call `Nest()` themselves; an extra `Nest()` throws `No Current element to nest into!`. Each nesting call needs one `NestOut()`.
- `SplitHorizontally(proportion, out left, out right, gap)` and `SplitVertically(...)`: `gap` is a **fraction** of the size, not pixels.
- `HorizontalHeader(size, ...)` is a strip across the **top**; `VerticalHeader(size, ...)` is a column on the **left**.
- `NestInto(rect)` pushes a root and clears `Current`; `NestOut()` pops and sets `Current` to the popped root.
- `new UIBuilder(RectTransform)` roots the builder at that rect's slot (used for pooled cards).

## Icon and animation facts (2026-11-02, ilspy)

- `RadiantDashButton.Setup` builds the icon sprite from `screen.Icon.Value` once (`AttachSprite`); changing `Icon` later does not update the button.
- `FrooxEngine.Store.LocalDB.ImportLocalAssetAsync(string path, LocalDB.ImportLocation location, ...)` hashes the file, returns the existing `local://` URL when the signature is already known, else copies or moves it into the asset store and returns a new `local://` URL. `ImportLocation` = Original, Copy, Move.
- `TweenExtensions.TweenTo/TweenFrom/TweenFromTo` attach a `Tween<T>` component to the field's nearest slot after clearing that field's earlier tweens. `Tween<T>` sets itself non-persistent, runs in `OnCommonUpdate`, and destroys itself when done. It calls `OnDoneLocal` on finish **and** on early destroy (`OnDestroy`, `OnDispose`). On an inactive slot it jumps to the final value and destroys itself at once.
- `CurvePreset` (FrooxEngine) has Linear, Sine, Smooth, SineIn/Out/InOut, Cubic*, Quartic*, Exponential*, Circular*, Rebound*, Elastic*, Bounce*.
- `InteractionElement.ColorDriver.SetColors(colorX)` sets the normal, hover and press colours; `NormalColor` is a plain field that can be tweened.
