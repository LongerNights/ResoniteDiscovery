| 2026-11-02 | ~~M2: the MonkeyLoader shim (`GalaxySieveMonkey`, a `ResoniteMonkey<T>`...) lives in `Discover.Resonite/Loader/`~~ SUPERSEDED by the loader change above; the part that stands: the shim lives in `Discover.Resonite/Loader/` behind a `#if`, not in a separate project | Spec Integration §6 says build the shims from the same project via `ResoniteTargetModLoader` |
| 2026-11-02 | `Discover.Resonite` compiles Core's source files into its own assembly (linked `Compile` items) instead of a `ProjectReference` | Originally because a ProjectReference became a NuGet dependency on a non-existent `Discover.Core` package that MonkeyLoader could not resolve.
